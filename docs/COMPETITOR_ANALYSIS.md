# Анализ конкурентов: Голосовые диктовщики для macOS

## Обзор рынка

Рынок голосовых диктовщиков для macOS активно развивается благодаря появлению OpenAI Whisper — открытой модели распознавания речи с высокой точностью. Основные игроки делятся на две категории: **AI-улучшенные диктовщики** (Wispr Flow, SuperWhisper) и **транскрибаторы аудио** (MacWhisper, Whisper Transcription).

---

## 1. Wispr Flow (wisprflow.ai)

### Бизнес-модель
- **Freemium**: Бесплатный план с ограничениями + Pro подписка
- **Ценообразование**:
  - Basic (Free): 2,000 слов/неделя на desktop, 1,000 на iPhone
  - Pro: $15/мес ($12/мес при годовой оплате) — безлимит
  - Enterprise: кастомная цена с SSO, SOC 2, HIPAA
- **Студенческая скидка**: 3 месяца бесплатно + 50% скидка

### Ключевые фичи
- **AI Auto Edits**: автоматическое удаление слов-паразитов, форматирование списков, пунктуация
- **Personal Dictionary**: автоматическое обучение уникальным словам
- **Snippets**: голосовые шорткаты для часто используемых фраз
- **Multi-tone**: автоматическая адаптация стиля под приложение (формальный/неформальный)
- **100+ языков** с автоматическим определением
- **Cross-platform**: Mac, Windows, iPhone, Android с синхронизацией
- **Command Mode**: голосовое редактирование текста
- **HIPAA-ready** на всех планах

### UX-паттерны
| Элемент | Реализация |
|---------|------------|
| Активация | Глобальный hotkey (не указан явно) |
| Индикатор записи | Плавающий оверлей или системный индикатор |
| Вставка текста | Прямая инъекция в активное текстовое поле |
| Обратная связь | Визуальная волна голоса, статус обработки |
| Остановка | Автоматическая по паузе или ручная |

### Технические решения
- Интеграция с Cursor, VS Code для теггинга файлов
- Распознавание camelCase, snake_case для разработчиков
- Контекстно-зависимая транскрипция
- Zero Data Retention режим (Privacy Mode)

## 2. SuperWhisper (superwhisper.com)

### Бизнес-модель
- **Freemium**: 15 минут бесплатного использования Pro фич
- **Ценообразование**:
  - Free: базовый voice-to-text, неограниченное использование small AI моделей
  - Pro: $8.49/мес (40% скидка для студентов) — доступ к cloud и local AI моделям, собственные API keys
  - Enterprise: кастомная цена с SOC 2 Type II

### Ключевые фичи
- **Modes**: предустановленные и кастомные режимы для разных задач (Message, Custom)
- **Super Mode**: AI-режим с адаптацией к экрану (контекстная осведомленность)
- **Context-Aware AI**: понимание контекста текущей задачи
- **File Transcription**: загрузка аудио/видео файлов
- **Push to Talk**: режим "нажал-говоришь-отпустил"
- **Local AI Models**: работа с локальными моделями без интернета
- **Bring Your Own API Key**: интеграция OpenAI, Anthropic, Deepgram, Groq
- **100+ языков** с переводом на английский "на лету"

### UX-паттерны
| Элемент | Реализация |
|---------|------------|
| Активация | Кастомный hotkey (⌘W по умолчанию) |
| Индикатор записи | Menu bar иконка с анимацией |
| Вставка текста | Инъекция в активное поле + буфер обмена |
| Обратная связь | Звуковой сигнал начала/окончания |
| Push-to-Talk | Удержание клавиши для записи |

### Технические решения
- Интеграция с Cursor, Claude Code, Open Code, Amp, Codex
- Выбор между GPT, Claude, Llama моделями
- Локальная обработка на устройстве (iPhone 13+, M-series iPad)

## 3. MacWhisper (goodsnooze.gumroad.com)

### Бизнес-модель
- **One-time purchase**: чистая покупка без подписки
- **Ценообразование**: не указано явно, обычно ~$10-20 (Gumroad модель)
- **Open Source**: код доступен (ограниченная функциональность)

### Ключевые фичи
- **Local Whisper**: работа с локальными моделями OpenAI Whisper
- **File Transcription**: основной фокус на транскрипции файлов
- **Offline**: полностью локальная обработка
- **Поддержка форматов**: mp3, wav, m4a, mp4, mov
- **AI Summaries**: генерация кратких выжимок
- **Chat with Transcripts**: возможность задавать вопросы к тексту

### UX-паттерны
- Простой drag-anddrop интерфейс
- Batch обработка файлов
- Визуальный прогресс транскрипции

### Технические решения
- OpenAI Whisper на устройстве
- Нет облачной обработки (приватность)
- Работа через Share Extension

## 4. Whisper Transcription (App Store)

### Бизнес-модель
- **Freemium**: базовые функции бесплатно
- **Ценообразование** (In-App Purchases):
  - Pro: $6.99/мес, $29.99/год, $8.99/мес альтернатива
  - Pro Lifetime: $99.99
  - Assistant (Cloud): $5.99/нед, $9.99/мес, $89.99/год
  - Combo Pro + Assistant: $12.99

### Ключевые фичи
- **Share Extension**: транскрипция из любого приложения
- **Cloud + Local**: выбор между облачной и локальной транскрипцией
- **Offline Mode**: локальные модели для приватности
- **100 языков**
- **AI Summaries**
- **Chat with Transcripts**

### Платформы
- iOS 18+, iPadOS 18+, macOS 14+, visionOS 2+

## 5. OpenAI Whisper (github.com/openai/whisper)

### Бизнес-модель
- **Open Source**: полностью бесплатный (MIT License)
- **Self-hosted**: требует собственной инфраструктуры

### Технические характеристики
| Модель | Параметры | VRAM | Относительная скорость |
|--------|-----------|------|------------------------|
| tiny | 39M | ~1GB | ~10x |
| base | 74M | ~1GB | ~7x |
| small | 244M | ~2GB | ~4x |
| medium | 769M | ~5GB | ~2x |
| large | 1550M | ~10GB | 1x |
| turbo | 809M | ~6GB | ~8x |

### Возможности
- Мультиязычное распознавание
- Перевод в английский
- Определение языка
- Python API и CLI

## 6. Русскоязычные аналоги

### Ситуация на рынке
- **Нет специализированных решений**: нативных macOS диктовщиков с AI-улучшением для русского языка нет
- **Яндекс SpeechKit**: API для разработчиков, нет готового consumer приложения
- **Сбер SaluteSpeech**: enterprise-ориентированное решение
- **VK Speech**: облачное API, нет desktop клиента
- **Apple Dictation**: встроенная в macOS, но без AI-улучшения и специализированных фич

### Пробел (Gap) на рынке
- Нет решения с AI-улучшением текста на русском языке
- Нет специализированных режимов для русскоязычных сценариев
- Нет интеграции с русскоязычными инструментами

## SWOT-анализ рынка

### Strengths (Сильные стороны рынка)
- Высокий спрос на продуктивность и автоматизацию
- OpenAI Whisper обеспечивает качественную базовую транскрипцию
- Пользователи готовы платить за удобство и экономию времени
- Сильный product-market fit для разработчиков и писателей

### Weaknesses (Слабые стороны рынка)
- Высокая зависимость от AI API (стоимость, latency)
- Сложность локальной интеграции на macOS (sandbox, permissions)
- Отсутствие стандартов UX для голосовых интерфейсов

### Opportunities (Возможности для Flow Mac)
- **Русскоязычный рынок**: нет специализированного решения
- **Локальная обработка**: приватность тренд
- **Bring Your Own API**: экономия для power users
- **macOS-only фокус**: глубокая интеграция с системой
- **One-time purchase**: альтернатива подпискам

### Threats (Угрозы)
- Apple может улучшить встроенный Dictation
- OpenAI может выпустить официальный клиент
- Ценовая война с крупными игроками
- Зависимость от Whisper API pricing

## Gap-анализ: Что упущено конкурентами

### 1. Проблемы Wispr Flow
- **Нет локальных моделей**: требует интернета
- **Нет BYOK**: нельзя использовать свой API key
- **Высокая цена**: $12-15/мес для unlimited
- **Нет push-to-talk**: только toggle режим
- **Ограниченная кастомизация**: нельзя создавать собственные режимы

### 2. Проблемы SuperWhisper
- **Сложность**: перегружен интерфейс
- **Нет snippets**: нет голосовых шорткатов
- **Нет dictionary**: не запоминает слова
- **Менее polished UI**: ощущается как tool, не продукт

### 3. Проблемы MacWhisper
- **Нет AI улучшения**: только чистая транскрипция
- **Нет real-time**: только файлы
- **Нет global hotkey**: не работает в любом приложении
- **Устаревший UI**: базовый интерфейс

### 4. Общие проблемы рынка
- **Нет фокуса на русском**: все решения — западные
- **Subscription fatigue**: пользователи устали от подписок
- **Нет open source**: нельзя самостоятельно развивать
- **Слабая интеграция с macOS**: не используются нативные фичи

## Рекомендации по MVP для Flow Mac

### Must Have (Core MVP)
1. **Глобальный hotkey** для активации (⌥Space или кастомный)
2. **Real-time транскрипция** с Whisper API
3. **Прямая вставка** в активное текстовое поле
4. **Визуальный индикатор** записи (плавающее окно или menu bar)
5. **Поддержка русского и английского** языков
6. **Автоматическая пунктуация** базового уровня

### Should Have (v1.1)
1. **Personal Dictionary**: запоминание специфичных слов
2. **Snippets**: голосовые шорткаты
3. **BYOK**: возможность использовать свой OpenAI API key
4. **Push-to-Talk режим**: удержание клавиши для записи
5. **Локальные модели**: offline транскрипция (whisper.cpp)

### Could Have (v1.2)
1. **AI улучшение текста**: улучшение грамматики, стиля
2. **Custom Modes**: разные режимы для разных задач
3. **File Transcription**: транскрипция файлов
4. **iOS companion app**: базовая синхронизация

### Won't Have (v2+)
1. **Windows/Android**: фокус на macOS
2. **Enterprise фичи**: SSO, HIPAA (пока)
3. **Real-time коллаборация**: сложно для MVP

## Технические выводы для реализации

### Audio Capture
```
Рекомендуемый подход:
- AVAudioEngine для capture
- Tap на inputNode
- Buffer размером 1024-4096 samples
- Sample rate 16kHz (оптимально для Whisper)
- Формат: Float32 → Int16 PCM
```

### Text Injection
```
Рекомендуемый подход:
1. CGEventTap для отслеживания активного поля
2. AppleScript/System Events для вставки:
   - tell application "System Events" to keystroke "text"
3. Альтернатива: Clipboard paste simulation
4. Accessibility API для определения text field
```

### Global Hotkeys
```
Рекомендуемый подход:
- NSEvent.addGlobalMonitorForEvents для отслеживания
- MASShortcut или SRRecorder для настройки
- RegisterEventHotKey (Carbon) для надежности
- Accessibility permissions required
```

### Whisper Integration
```
Варианты:
1. OpenAI API (рекомендуется для MVP):
   - Латентность ~500ms-2s
   - Цена: $0.006/минута
   - Лучшее качество
   
2. whisper.cpp (локально):
   - Без задержек сети
   - Требует ресурсов
   - Модели: tiny (39MB) → large (3GB)
   
3. Groq/Deepgram API:
   - Быстрее OpenAI
   - BYOK модель
```

### UI/UX Patterns
```
Индикатор записи:
- Menu bar icon с анимацией (как SuperWhisper)
- Или плавающее окно (как Wispr Flow)
- Waveform visualization опционально

Настройки:
- Menu bar dropdown
- Или Settings window (SwiftUI)
- Горячие клавиши в System Preferences
```

### Sandbox & Security
```
Требуемые entitlements:
- com.apple.security.device.microphone
- com.apple.security.automation.apple-events (для text injection)
- com.apple.security.accessibility (для global hotkeys)
- НЕ sandbox-friendly для text injection!

Решение:
- Распространение вне Mac App Store
- Или ограниченная функциональность в MAS
```

## Выводы

### Рыночная позиция
Wispr Flow — лидер по UX и AI-функциям, SuperWhisper — лидер по технической гибкости, MacWhisper — нишевое решение для приватности.

### Возможность для Flow Mac
**Ниша**: macOS-only диктовщик с фокусом на русский язык, локальную обработку и BYOK модель. Альтернатива дорогим подпискам с one-time purchase или freemium моделью.

### Ключевое отличие
Глубокая интеграция с macOS + поддержка русского языка на уровне лучших английских решений + гибкость в выборе моделей (cloud/local/BYOK).
